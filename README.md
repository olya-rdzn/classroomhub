# ClassroomHub

My little classroom response app. Students join from one permanent link per course. 

No names, no account, no sign-up, 100% anonymous.

## Student's side

One link opens the current live lesson. Students can add input on:

- **Question wall** — ask anything about the lesson.
- **Exit ticket** — main thing learned, and what is still unclear.
- **Feedback box** — comments on pace, materials, or anything to revisit later.
- **Confidence meter** — rate understanding 1–5, from Lost to Got it.

## Professor's side

- **Courses** — create courses
- **Lessons** — add lessons to a course
- **Live controls** — open/close submissions, end the session
- **Live views** — one panel per tool
